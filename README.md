# EchoTrace

נוכחות דיגיטלית מינימלית של אדם אחד על מסך הבית של אדם אחר.

אין אתר, אין ממשק ניהול, אין מסכים. הכול קורה דרך וידג׳ט אחד: תמונה אחת מגיעה, נראית, ודוהה עם הזמן - עד שהופכת לצבע-זיכרון, ומתחלפת בתמונה חדשה.

## מה יש כאן

- `android/` - אפליקיית אנדרואיד (Kotlin). הווידג׳ט הוא הממשק היחיד: זיווג, צפייה, שליחה.
- `server/` - שרת Cloudflare Workers + KV. שכבת תיווך זמנית בלבד.

## עקרונות המוצר (מהאפיון)

- אדם אחד בלבד - כל מכשיר מחובר לאדם אחד, לכל חיי ההתקנה. השרת דוחה זיווג כפול.
- תמונה אחת בכל רגע - תמונה חדשה מחליפה את הקודמת, בלי ארכיון ובלי היסטוריה.
- התמונה נמחקת מהשרת מיד עם אישור ההורדה. היא קיימת רק על מכשיר הצופה.
- ניתוק קיים רק דרך מחיקת האפליקציה.

## הדעיכה (מנוהלת במכשיר הצופה)

| זמן מהחשיפה | מראה |
|---|---|
| 0-6 שעות | תמונה חדה, כיתוב ברור |
| 6-12 שעות | טשטוש עולה מ-0 ל-25, הכיתוב דוהה |
| 12-24 שעות | טשטוש מרבי + צבע-זיכרון חם שמחושב מהתמונה |
| 24+ שעות | צבע-זיכרון בלבד |

צבע-זיכרון: ממוצע של הפיקסלים החמים (אדום-כתום-ורוד) בתמונה, מרוכך לגוון חול.

## הזיווג

הקוד האישי (6 תווים, ללא תווים דומים) הוא מזהה המכשיר. כל צד מזין את קוד השני בווידג׳ט. אין אימייל, אין טלפון, אין חשבון.

## הרצת השרת

דרוש חשבון Cloudflare בחינם.

```bash
cd server
npm install
# יצירת מרחב KV (פעם אחת) והדבקת ה-id ב-wrangler.toml
npx wrangler kv namespace create ECHOTRACE
npx wrangler deploy
```

השרת חי כרגע בכתובת:
`https://echotrace-server.gamal-hametzaits.workers.dev`

נקודות קצה: `/register` `/connect` `/upload` `/poll/:deviceId` `/image/:imageId` `/confirm-download` `/partner-status/:deviceId`

## בניית ה-APK

דרושים JDK 17 ו-Android SDK (platform 33, build-tools 33).

```bash
cd android
export ECHOTRACE_SERVER_URL=https://echotrace-server.gamal-hametzaits.workers.dev
export ECHOTRACE_KEYSTORE=/path/to/echotrace.keystore
export ECHOTRACE_STORE_PASSWORD=...
export ECHOTRACE_KEY_PASSWORD=...
./gradlew assembleRelease
```

המפתח החותם לא נמצא בריפו. בלי משתני הסביבה אפשר לבנות `assembleDebug` חתום במפתח דיבוג מקומי.

## החלטות הנדסיות והחרגות מהאפיון (שקיפות מלאה)

- **Cloudflare Workers במקום Vercel** - Vercel דרש אימות SMS במספר טלפון; Cloudflare עובד בחינם עם אימייל בלבד. תמונות נשמרות ב-KV (לא R2, שדורש כרטיס אשראי גם במסלול החינמי).
- **סקר במקום FCM** - במקום Firebase Cloud Messaging, הווידג׳ט סוקר את השרת כל 15 דקות דרך WorkManager (המינימום שאנדרואיד מאפשר לעבודה תקופתית). פירושו: תמונה חדשה מופיעה תוך עד 15 דקות, לא מיידית. אין תלות ב-Firebase, הכול חינם.
- **שעון הדעיכה מתחיל ברגע ההצגה** - ווידג׳ט על מסך הבית גלוי תמיד, אז "חשיפה ראשונה" היא רגע ההורדה וההצגה, לא הלחיצה. לחיצה על התמונה מסמנת "נצפתה".
- **לחיצה ארוכה לא קיימת בווידג׳טים** - RemoteViews של אנדרואיד לא תומך בלחיצה ארוכה. במקום: במצב "הקשר נותק", לחיצה רגילה פותחת דיאלוג "התחלה מחדש".
- **אנימציות בועה/דופק** - לא ניתנות לביצוע בתוך RemoteViews. התמונה מופיעה/מתחלפת בלי אנימציה.
- **זיהוי "הקשר נותק"** - מחיקת אפליקציה לא מדווחת לשרת. השרת מסיק ניתוק מדופק חיים: אם הצד השני לא פנה 5 ימים, הווידג׳ט מציג "הקשר נותק".
- **כיתוב** - ה-API תומך בכיתוב עד 50 תווים (`x-caption`), אבל לפי כלל הברזל "אין כפתור שליחה, אין עריכה" האפליקציה שולחת מיד אחרי הצילום בלי שלב עריכה. שדה כיתוב יכול להתווסף בשלב הבא.
- **מסך הזנת קוד** - שדה קלט אמיתי לא אפשרי בתוך ווידג׳ט; לחיצה על הווידג׳ט במצב זיווג פותחת דיאלוג קטן להזנת הקוד. זו דרישת פלטפורמה של אנדרואיד, לא חריגה מהרוח.
